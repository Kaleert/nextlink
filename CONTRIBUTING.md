# Вклад в Nextlink

Спасибо за желание помочь. Сейчас основное направление — **Android**: стабильность VPN, корректное переключение ядер, удобство интерфейса и воспроизводимая сборка. Linux-релизы пока на паузе.

## Перед PR

1. Проверь, нет ли уже похожей задачи или обсуждения.
2. Для крупных изменений сначала опиши проблему и предполагаемое решение в Issue.
3. Делай PR по возможности на одну тему: баг, UI, движок или сборка.
4. Не добавляй приватные конфигурации, подписки, пользовательские логи, keystore и скомпилированные Shadow-ядра.

## Локальная разработка

```bash
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test test/core/models test/core/utils test/core/engine test/core/localization --exclude-tags network
python3 -m unittest discover -s test/python -v
flutter build apk --debug --flavor original --target-platform android-arm64
```

Тест `test/core/xray_download_test.dart` обращается к реальному GitHub API и **не включён в обязательный CI**. Используй его вручную для диагностики загрузок; HTTP 502/503/504 не обязательно означает регрессию клиента.

## Что проверять руками

| Изменение | Минимальный smoke test |
|---|---|
| Подключение / TUN | Старт, стоп, повторный старт, отключение из системы |
| Ядра | Подключение отдельно через затронутый движок |
| Маршрутизация / LAN | Доступ к локальному адресу во время VPN и после отключения |
| Фоновая работа | Уведомление, переключение сети, повторный вход в приложение |
| Подписки | Импорт, обновление, ошибочная ссылка, дубликаты |
| Shadow | Чистая установка без загрузок; встроенные ядра и GeoIP/GeoSite видны в Центре ресурсов |
| UI | Маленький экран, пустой список серверов, RU/UK/EN, светлая и тёмная темы |

`BUILD SUCCESSFUL` — только компиляция, **не подтверждение**, что VPN работает на устройстве.

## Нативные зависимости

`tun2socks/` — Git submodule; патчи Nextlink лежат отдельно в `patches/`. Подготовка исходников:

```bash
git submodule update --init -- tun2socks
bash scripts/prepare_tun_bridge.sh
```

Собранные `.so` для Shadow и ключи подписи остаются вне Git. Подробнее: [Android releases](docs/android-release.md).

## Описание PR

Укажи **что изменилось**, **зачем**, **как проверил**, и **какие ограничения остались**. Для визуальных изменений приложи скриншоты до/после. В отчётах об ошибках замени чувствительные значения маркерами вроде `example.com`.
